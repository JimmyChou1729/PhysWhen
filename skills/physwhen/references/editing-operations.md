# Triggered editorial operations

Use only operations that solve an observed problem. All examples below are **synthetic interface examples**, not quotations or findings from the 500-paper corpus. A clearer-looking sentence is not proof of comprehension benefit. Follow SKILL.md's scientific boundary; locating support does not authorize adding science.

## O1 — Resolve a competing referent

**Trigger:** “this result”, “it” or “this behavior” could refer to more than one nearby object or result.

**Operation:** Identify the intended referent in the supplied material. Name it or use an accurate existing equation/result pointer, then check subsequent pronouns.

**Preserve:** The referent's identity, restrictions and relation to the next statement. If the referent cannot be recovered, flag ambiguity rather than guess.

**Synthetic repair:** Notes say a bound is useful because it is independent of u. Draft: “The rate grows with u. The bound is independent of u. This result is useful for comparing u.” Replace only the third sentence with “The u-independent bound is useful for comparing choices of u”; retain the first two scientific statements. Do not attribute independence to the rate.

**Leave unchanged:** “The bound is independent of u. This independence lets us use the same bound across the comparison.” The antecedent is already clear; repeating the whole term would add no help.

## O2 — Expose the supplied paragraph-to-paragraph relation

**Trigger:** A paragraph changes object, regime or task without telling the reader how it connects to the previous passage; or several paragraphs repeat information without moving the argument.

**Operation:** Determine what the next paragraph continues and contributes: definition, consequence, special case, contrast, diagnostic, independent result or limitation. Add only the missing connection, move an existing definition with its use, or consolidate repetition with no distinct function. A paragraph can perform several functions; do not enforce a role template.

**Preserve:** Actual dependencies and the distinction between existence, stability, observation and interpretation. “Therefore” is appropriate only when the supplied relation warrants it.

**Synthetic repair:** Notes already contain a static solution, a stated stability question and a separate supplied linear-perturbation analysis. Draft: “We construct a static solution. We next consider the perturbation equation.” Retain the static-solution statement and replace only the transition with “We next ask how the static solution responds to the small perturbations considered in the supplied analysis.” Mention linearization only if that operation is actually provided. Without that support, flag the missing link.

**Leave unchanged:** A result-first preview explicitly points to its later derivation, or a recap at a new regime repeats the result with a different supplied condition. Earlier occurrence alone does not make repetition wasteful.

## O3 — Establish a term's identity before changing it

**Trigger:** An unfamiliar label, shifting name, or apparent technical coinage obstructs meaning.

**Operation:** Classify its role in context: established specialist term; explicitly author-defined new concept; ordinary descriptive phrase; or unresolved technical label. Inspect the supplied definition and relevant retrieved usage. Preserve a legitimate new name and its distinction from existing concepts. Use an ordinary phrase freely when it is not claiming to be a named theory.

**Preserve:** Concept, notation, definition, scope and consistent naming. A literature occurrence is not evidence of equivalent meaning in this manuscript. A search miss does not prove invalidity.

**Synthetic repair:** “Response index” is defined as R=(A-B)/(A+B), A+B>0. Introduce the definition once and use the same name. If its name suggests a mechanism, state the supplied diagnostic role rather than asserting that mechanism.

**Leave unchanged:** “Gauge-invariant curvature perturbation” or a clearly defined author-specific diagnostic. Do not replace a correct specialist term merely because simpler words exist. Do not force every one-off descriptive phrase into a glossary.

## O4 — Replace decorative collocation with a recoverable proposition

**Trigger:** Each word is recognizable, but the noun cluster or vague verb does not identify an object, operation or relation.

**Operation:** Ask what the supplied material says is done to which object, by which existing condition, and within which scope. Rewrite directly only when that relation is supplied; otherwise flag missing meaning separately. Treat retrieved collocations as contextual examples, not frequency-based laws.

**Preserve:** Causal status, approximation, diagnostic/mechanism distinction, quantifiers and scientific strength.

**Synthetic repair:** Notes: c is the undetermined integration constant; imposing f(1)=0 gives c=2. Draft: “Boundary admissibility completion operationalizes constant selection.” Repair: “We fix c=2 by imposing f(1)=0.” This makes the supplied operation visible; it adds no derivation.

**Leave unchanged:** “Imposing f(1)=0 fixes c=2.” Extra context or more formal nouns would not improve this already definite statement. If no notes define what a “coherence transfer horizon” does, do not invent a physical interpretation to rescue the sentence.

## O5 — Explain an existing step without doing new science

**Trigger:** An already supplied derivation has a recoverable dependency that the prose does not make visible.

**Operation:** Locate the actual step and its stated condition, then name their relationship: substitution, use of an existing assumption, comparison, restriction or application of a previously stated result. A pointer or one sentence may suffice. If the derivation is absent or the relationship uncertain, leave a separate question.

**Preserve:** Every necessary step and scientific claim. A new lemma, extra assumption, new limiting argument or independent calculation is not editorial explanation.

**Synthetic repair:** Material explicitly says K is constant and supplies R=Kx, then discusses changing x. “With K held fixed, this supplied relation describes how R changes with x” is an editorial restatement. Deriving a new dependence on K is not authorized.

**Leave unchanged:** Consecutive transparent algebra with all definitions available, or a long sentence needed to preserve “for every background there exists a solution” rather than “one solution for every background.” Do not split away or reverse quantifier scope for rhythm.

## Compact inspection for a sequence of paragraphs

For a difficult sequence, track the object/claim carried forward, the new contribution, and the real relation between paragraphs. Record a short local map only when useful. Apply a change only when it addresses a concrete ambiguity, jump or repetition. Check the final sequence against the supplied science, including conditions that must move with a result. Do not add a compulsory transition, explanation or rewrite to every paragraph.
