# 使用 PhysWhen skill

## 一句话开始

安装后，附上稿件或笔记，说“请使用 physwhen 修改这篇论文”或“请使用 physwhen 根据这些笔记写论文”即可。保留科学内容、按任务选择整体或局部操作等要求已经写入skill，无需每次复制长提示词。

有现成稿件时，以原稿的篇幅和读者为默认；新写作根据材料推断合理范围。可以额外指定字数、读者、投稿格式或禁止改动的部分，但不要求填写固定清单。只有缺少关键科学内容时才需要补充说明；只有题目时先做明确标注的提纲或询问研究结果，不编造原创发现。

默认返回所请求的正文或大纲。需要查看规划时，再要求问题、主张、证据和条件的对应关系。

## 更新与旧安装迁移

对外始终只有 `physwhen`，源码位于 `skills/physwhen/`，分发包是 `deliverables/PhysWhen-skill.zip`。`git pull --ff-only` 更新仓库；本地复制安装不会自动跟随仓库更新。更新时将旧安装移到skill发现目录之外留作备份，再把新的完整 `physwhen/` 文件夹复制进去，避免遗留已删除的资源。如果改过安装副本，先比较差异。

曾安装 `physics-paper-style-v3` 等旧名称时，也先在宿主停用或移出发现目录，再安装 `physwhen`，避免同时出现两个入口。本次仓库变更不会自动改动任何全局安装。

历史研究脚本、论文版本、数据协议和实验批次仍保留原编号，以便追溯；这些不是并行维护的产品版本。准确复现实验需用原冻结快照，不应把最新skill替换进去。

## 可选：大纲结构检查

仓库提供一个合成示例，只用于演示接口，不代表真实物理结论或实验结果：

```bash
python3 skills/physwhen/scripts/check_outline.py examples/outline.json
```

成功时输出 `status: pass`。把示例替换为自己的大纲后，工具检查 ID 是否存在、已回答的问题是否指向主张、声明有支持的主张是否列出证据，以及主张和条件是否在章节安排中出现。

它无法判断证据是否真的证明结论。不能把 `pass` 写成“物理正确”或“可读性已改善”。JSON 字段详见 [outline-contract.md](../skills/physwhen/references/outline-contract.md)。

## 检查是否完整使用

需要完整论文重组时，让 agent 读取 `SKILL.md`，并按入口要求查阅相关 `references/`。只看名称或把 skill 的几条摘要复制进提示词，不等于使用完整版本。局部润色只需相关操作，无须强制读取所有研究材料。

如果安装后没有出现，先确认 skill 文件夹没有被多嵌套一层，再检查宿主的发现目录。Codex 的本地路径、显式调用与重启说明以 [官方文档](https://learn.chatgpt.com/docs/build-skills) 为准。本仓库当前交付的是独立 skill 文件夹，未注册插件市场。

## 阅读实验

下载 `deliverables/PhysWhen-Blind-Test-03.html` 或同名 ZIP，保存后用电脑浏览器打开。聊天软件预览可能不能运行脚本。每组读完两版后选 X、Y、相近或无法判断；理由和背景选填。完成一组也可以下载结果交回。

问卷标识为 `pair-preference-v1`，只测整体主观偏好，不测理解正确率，也不单独测自然度和费力程度。匿名代号用于合并多次导出，不等于核实过的唯一真人。旧问卷与新版分开汇总；组织者本地保留解盲映射，不向参与者分发。

## 术语与句意检查

现在默认检查不明组合词、术语同义替换和没有明确物理关系的句子。优先依据稿件定义和相关文献，保留必要的专业术语及作者已定义的新概念。含义不确定时标出问题，不把“不熟悉”或“未在500篇中出现”当作不存在的证据，也不把不清楚的句子润色成未经支持的结论。无需额外提示词即可使用；需要检查过程时可要求“列出含义不明的术语及修改理由”。

## 默认执行的完整流程

新写和修改都先检索领域文献与术语，实际读源，用于表达、术语和结构参考。先记录用户材料的科学主张、条件与原位置；整篇编辑再比较当前结构与可行替代路线，必要时重排章节、合并或拆分内容、移动已有论证块，并修复编号及交叉引用。一般“修改这篇论文”就包含这种结构判断，不需要额外口令；局部编辑仍保持局部范围。

修改不得改变模型、定义、方程、假设、证明步骤、结果或结论强度。原内容缺乏依据或与文献有冲突时，只在正文之外列出问题，不能擅自增补假设、弱化结论、修理证明；即使在变更说明中解释也不等于获得授权。科学修改必须由用户另行明确要求。

写后做内容保留和可读性检查。重排时记录旧位置到新位置，避免丢失科学单元；仅改标题或加导语要如实称为局部呈现优化。只有PDF时说明公式核对的局限，不承诺全稿数学等价。无法检索时如实说明，继续有明确限制的工作。详见 [evidence-workflow.md](../skills/physwhen/references/evidence-workflow.md)。
